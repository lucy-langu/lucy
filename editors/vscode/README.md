Syntax highlighting for the **Lucy** programming language in Visual Studio Code.

## ✨ Features

- 🎨 Syntax highlighting for `.lucy` files
- 💬 Line (`#`) and block (`=begin` / `=end`) comments
- 🔤 String highlighting with interpolation (`$var`)
- 🔢 Number, operator, and constant highlighting
- 🧩 Auto-closing brackets, quotes, and backticks
- 🎯 Smart function/class name highlighting

## 📦 Installation

### From VS Code Marketplace
Search for **"Lucy Language"** in the Extensions panel.

### From VSIX
```bash
code --install-extension lucy-language-1.1.1.vsix
